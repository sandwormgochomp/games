Making an animation: draw frame 1, hit Duplicate, nudge things, repeat. Turn on Onion skin to see the frame before (red) and after (blue) the one you're on. Hold makes a frame last longer without redrawing it. When it looks right, Export GIF.

Saving: Save keeps the project inside this browser under a name — Ctrl+S overwrites it after that. Open… lists everything you've saved. You never have to remember: every edit is auto-saved a second later, and reopening the page recovers whatever you were working on. The dot beside the project name means unsaved changes. Export .json writes a real file you can back up or move to another computer.
